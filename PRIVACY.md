Privacy Policy for Triple J Extension

1\. **Data Collection & Usage**

Triple J Extension does not collect, store, retain, or transmit any personal data, browsing history, or user information.

2\. **On-Page Script Execution**

The extension executes a local content script strictly to read the visible audio player timer and automatically adjust page scroll and element highlighting on the target website. All script processing occurs locally within the user's browser in real time.

3\. **Third-Party Sharing & Remote Servers**

No data is shared with third parties, and no data is ever sent to external servers or remote locations.

4\. **Contact Information**

If you have any questions regarding this policy, you can contact the developer via GitHub or the Chrome Web Store support page.
